# Lessons learned from my decisions

Rules the agent derives from the candidate's Pursue/Discard decisions and notes. Read before every search and scoring. One rule per line, with the job ID(s) it came from.

**How to learn from the notes: don't be too harsh.** A mild comment ("not so much into X", "not really my thing") means LOWER the score for similar jobs, not exclude them. Only exclude when the candidate says it clearly ("no", "never", "I don't want X") or when it is a hard limit (language, location, seniority, closed job). Mild preferences go under "Score lower".

## Discard patterns (hard rules – leave these jobs out)
- Always check the posting is still open (see Skills/job-search.md, 4b).
- Never list the same role twice (reposts, duplicates): compare company + title, not only the link.
- Read the WHOLE posting for language requirements, not only the requirements list (a required language can hide in the "about you" text).
- Graduate/entry programmes that cap prior full-time experience below what the candidate has are a hard limit.
